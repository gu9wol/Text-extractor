# PADDOCK CLIPPER

모토원(Motivo 1) 테마 발췌기. 본문을 넣으면 이미지 카드로 만들어 주고, 카드 비율을 고정하면 넘치는 글은 다음 장으로 자동으로 이어집니다.

- 일반 모드 / 채팅 모드, 채팅 테마 9종 (TEAM RADIO · PADDOCK PASS · LIVE 중계 자막 · PIT BOARD 포함)
- 자동 페이지 넘김 (문단·말풍선 단위, 긴 문단은 글자 단위로 서식 유지하며 분할), `===` 강제 다음 장
- 2단 소설형, 페이지 번호, 글 길이에 맞추기
- 사진·스티커·프로필 6명·팀 컬러 팔레트, 타이틀·크레딧, 서체·자간·장평·행간
- 배경: 단색 / 그라데이션 / 패턴 / 이미지 / HTML
- 프리셋 보관함 (브라우저 저장, JSON 내보내기·가져오기)
- 전체 ZIP 저장, 장별 PNG 저장, 클립보드 복사 — 워터마크 없음

모든 작업은 브라우저 안에서만 처리되고 서버로 전송되지 않습니다.
